# Revista Digital MSB – valor-bfoam-msb

Revista digital da MSB Medical System do Brasil (HTML + CSS + JavaScript, sem servidor).

## Como atualizar as páginas
Substitua os arquivos `paginas/page-1.png` … `page-6.png` pelas páginas reais,
mantendo os mesmos nomes (todas com a mesma proporção). Substitua também `paginas/logo-msb.png` pelo logo oficial.
Se mudar o número de páginas, ajuste `TOTAL_PAGES` no início do `script.js`.

## Publicar no GitHub Pages
1. Envie todos os arquivos para o repositório `italozorzetto19/valor-bfoam-msb`.
2. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. Acesse: https://italozorzetto19.github.io/valor-bfoam-msb/

## Navegação
Clique nas laterais ou arraste a página · setas ← → · botões ‹ › · tela cheia com **F** ou ⛶.
